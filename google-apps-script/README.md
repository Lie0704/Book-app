# 로그인 없는 북크닉 웹앱

Google Sheets를 예약 저장소로 사용하는 Google Apps Script 웹앱입니다. 신청자는 Google 로그인이 필요하지 않습니다.

## 설치

1. 새 Google Sheet를 만듭니다.
2. `확장 프로그램 > Apps Script`를 엽니다.
3. 기본 코드 파일에 `Code.gs` 내용을 붙여 넣습니다.
4. `+ > HTML`로 `Index` 파일을 만들고 `Index.html` 내용을 붙여 넣습니다.
5. Apps Script 프로젝트의 시간대를 `Asia/Seoul`로 설정합니다.
6. `배포 > 새 배포`를 선택합니다.
7. 유형은 `웹 앱`, 실행 사용자는 `나`, 액세스 권한은 `모든 사용자`로 설정합니다.
8. 배포 후 표시되는 웹앱 URL을 신청자에게 공유합니다.

처음 배포할 때만 Google 계정 권한 승인이 필요합니다. 신청자는 URL 접속 후 로그인 없이 신청할 수 있습니다.

예약 데이터는 같은 Google Sheet의 `예약` 시트에 자동으로 기록됩니다. 날짜별 예약 현황은 웹앱 하단 달력에 표시됩니다.
